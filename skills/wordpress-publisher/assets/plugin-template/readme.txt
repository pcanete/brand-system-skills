== Description ==

Reemplaza únicamente la portada pública mediante la jerarquía de plantillas de
WordPress. Conserva wp_head(), wp_body_open() y wp_footer() para integraciones
como analítica, consentimiento y píxeles. Las demás rutas siguen bajo WordPress.

== Installation ==

1. Probar primero en staging y conservar una copia de seguridad.
2. Subir el ZIP desde Plugins > Añadir plugin > Subir plugin.
3. Activar {{PLUGIN_NAME}}.
4. Vaciar cachés y CDN cuando corresponda.
5. Verificar portada, cuenta, registro, tienda, carrito y formularios.

== Uninstallation ==
